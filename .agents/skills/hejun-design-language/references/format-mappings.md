# 格式映射

只阅读目标格式部分。共享颜色与内容，不把同一版面截图粘到所有格式。

## PPT / PPTX

优先使用五页官方 `hejun-official-red-v2026.pptx`。页型按顺序为封面、目录、章节、白底正文、结束。母版及图片背景保留，标题、正文、数据、表格与图示另用原生对象实现。官方模板自带 Logo 的位置不重复加标。

模板中的“请编辑标题内容”是制作占位符，交付前移除。源文件部分背景含不可编辑图形，这是素材特点；新加正文不得做成整页位图。用图表工具输出原生系列和标签，复杂图示保证至少文字和业务关系可编辑。图表注明单位、时间和来源。

旧 4:3 稿改版时先确认改版是否包含比例变化，不能拉伸。内容过满时删减重复、改为多页或附录，不沿袭历史文件里 7–12 pt 的密集正文。若受精确页数约束，向用户说明内容压缩的取舍。

## Word / DOCX

`hejun-starter.docx` 是跨格式推导模板。A4，建议四周 22 mm；正文 11 pt、1.35 倍行距，一级标题 18 pt。封面不把整张 16:9 PPT 背景硬塞进 A4。通过标题、细线和少量红色强调表达品牌。

正文保持原生段落和样式，标题用 Heading 1/2，表格保留可编辑单元格，长表重复表头，题注与图表相邻，数字对齐。页眉右上 Logo，页脚页码与项目名称；避免把页码写死。封面可使用品牌页眉，但不能重复叠加。目录用 Word 原生字段并在可用的文档引擎中更新。

## HTML / 离线 HTML

采用 semantic HTML、CSS 变量，中文无衬线字体栈。正文最大宽约 1120 px、17 px/1.7 行高，窄屏单列；长表在有标签的可滚动容器内，屏幕外无横向溢出。

网页封面可用红色标题区和白色品牌栏表达新版品牌，默认不添加动态效果。打印样式隐藏导航、保留信息层级、避免表格和标题孤行。离线交付保留完整源文件夹，并输出 `{项目}_Hejun_Standalone.html`。

`build_standalone_html.py` 支持静态 HTML 的本地 stylesheet、CSS url()、img src、icon link 和 classic script src。它不支持 CSS @import、srcset、模块脚本/JS 动态资源、iframe、远程展示资产或 video/audio/source/object/embed；遇到这些情况先整理成受支持结构或使用合适的构建工具，不声明不完整结果可离线。普通导航链接可以保留，但离线时外部链接仍需联网。

## PDF

按用途从可编辑 PPT、DOCX 或 HTML 导出。演示型 PDF 延续 16:9，正式报告用 A4。检查字体嵌入或替代、分页、链接、可搜索文本、图表清晰度。不以整页截图作为默认 PDF 制作方式。

生成后逐页渲染查看。PDF 视觉正确不代表可编辑源文件正确，因此二者分别验证。没有完成渲染时明确标注“未完成视觉验证”，不要宣称通过。

## 多格式

先建立共享内容模型：sections、claims、sources、tables、figures。每条数据携带原值、单位、期间、来源及限制。PPT 根据讲述节奏拆页，Word 展开逻辑，HTML 适配滚动阅读。核对不同格式的关键数字和结论一致，允许排版独立。
