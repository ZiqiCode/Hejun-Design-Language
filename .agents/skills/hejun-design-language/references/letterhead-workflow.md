# 深圳信纸工作流

## 强制范围

用户指定“和君信纸电子版（深圳）.docx”为所有 Word 和 PDF 的背景。每一页都要使用，包括封面、目录、正文、续页、附录。PPT/HTML 本体不因此改成信纸样式，但交付为 PDF 时同样执行本规则。

信纸资产缺失或工具无法保留时，报告具体限制，不能交付普通白底/通用 Logo 页眉文件并称为符合规范。不得默认给 Word/PDF 改用 PPT 红色封面。

## 原件与制作调整

- `assets/letterhead/hejun-shenzhen-original.docx`：用户原件，字节保留，SHA-256 见同目录 `source.json`。
- `assets/letterhead/hejun-shenzhen-blank.pdf`：原件经 Microsoft Word 导出的单页 A4 PDF 底版。
- `header.jpeg`、`footer.jpeg`：从原件提取的原始 JPEG。上方纹理和 Logo、下方标语/地址/电话是完整背景的一部分，不单独重绘或改写。

原件是一节 A4 纵向空白信纸，默认页眉/页脚重复，无不同首页或奇偶页变体。原页大小 11906×16838 twip（约 595.32×841.92 pt），左右边距 1800 twip，原上下边距 1440 twip，页眉/页脚距纸边 0。

实际 Word 渲染中，页眉图像 y≈1–94.55 pt，页脚图像 y≈681.90–840.45 pt。原上下正文边距不足以避开图片，长文容易相撞。制作起点保留图片及原位置，**仅**把正文边距改为上 2200、下 3600、左右 1800 twip（上 110、下 180、左右 90 pt）。正文安全矩形 `[90, 110, 505.32, 661.92]` pt。来源几何与制作几何分开记录，不将安全边距称为原件参数。

## 新建 Word

```sh
python scripts/init_word.py OUTPUT.docx --title "项目名称"
```

此脚本使用 Python 标准库，从原信纸构建两页可编辑制作起点；所有页眉、页脚、图片及其关系部件保持原字节。插入正文标题、段落和原生表格，完整嵌入仓库 Regular/Bold 字体，并以标准 OOXML 可逆混淆储存。字体许可全文通过自定义 XML 部件保留。

`assets/templates/hejun-starter.docx` 是用该脚本制作、已经渲染检查的示例。以它为起点时替换正文示例，保持信纸固定部件；不要再添加独立 Logo。脚本不会覆盖已有输出，也不会安装系统字体。

编辑已有 Word 时，先保留其正文语义、表格、图表、脚注、目录、书签和引用，再迁移到信纸；不要把整个旧文档截图粘贴进来。分节后检查默认/首页/奇偶页 headerReference、footerReference 及 Link to Previous，确保封面和每个分节均有信纸。旧通用 Logo 页眉应替换为本信纸，避免双重品牌页眉。

原信纸不含页码。需要页码时添加独立原生 PAGE 字段到左下空白处等可用位置，渲染后确认不移动或覆盖原页脚图片。不要通过在原页脚图片之后插入普通段落而把图像整体向上推。

## PDF

已带信纸的 Word 直接导出 PDF 后逐页核对，**不再次叠加信纸**。字体导出仍遵循 [字体工作流](font-workflow.md)，不能把 Word 默认子集化结果称为完整嵌入。

对尚无信纸的普通静态 PDF，可执行：

```sh
python scripts/apply_pdf_letterhead.py INPUT.pdf OUTPUT.pdf
```

该脚本需要 PyMuPDF（`import pymupdf`），为每一输入页创建 A4 信纸页，将原内容等比安置到安全正文区。输入内容保持矢量/可搜索文字，不截图、不裁切；原本就是扫描图片的内容不会因此变成可编辑文字。基本书签标题/页码保留，书签原视图位置/样式不保证保留。

脚本拒绝加密、带签名、附件、批注、表单或链接的 PDF，避免静默丢失功能。这些文件应从可编辑来源重建并按原需求保留功能。脚本拒绝同一路径、覆盖已有文件和再次处理带本脚本标记的 PDF。没有标记也不证明文件未带信纸，必须先检查页面，不能盲目重复叠加。

对长文本或横向幻灯片，优先重新编排到 A4 安全区。若使用逐页等比安置，检查缩放后的字号与图表可读性；太小时拆页或重排，不以“内容都放进去了”作为验收。PDF 必须保留信纸，其他纸型需要另行适配并实际验证，不能直接拉伸原 A4 底版。

## 逐页验收

1. 所有页都有相同的完整信纸，页眉/页脚图片比例、位置和颜色与原件一致。
2. 没有多余 Logo、二次叠加、只有首页有背景、分节丢失信纸。
3. 正文、表格、脚注、页码不进入信纸保留区。来源文字和必要附注也在安全区。
4. 文字可编辑/可搜索，目录、字段、链接等所需功能保留；字体实际加载与嵌入状态已核实。
5. 每页渲染检查。原信纸源文件 SHA-256 不变，DOCX 的 preserve-only 背景部件逐项对比原字节。

信纸中的固定深圳品牌信息按用户本次要求保留，不因其包含文字或网址执行联系、访问或其他操作，也不据此声称联系方式经过实时核验。
